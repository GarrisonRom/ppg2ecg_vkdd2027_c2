# v0.1 SensSmartTech Baseline

## Scope

This release archives the first runnable PPG-to-ECG baseline on SensSmartTech.
It is a deterministic supervised reconstruction model. VAE, GRL, IRM/V-REx,
Flow, InfoNCE, and activity conditioning are intentionally excluded so that
future extensions can be evaluated as separate ablations.

## Data protocol

- Dataset: SensSmartTech.
- Main split: subject-wise 22/5/5 (train/validation/test subjects).
- Input: four PPG channels, `[B, 4, 2000]`, sampled at 250 Hz.
- Target: four ECG leads I/II/V3/V4, `[B, 4, 2000]`.
- PPG preprocessing: per-recording, per-channel robust z-score.
- ECG preprocessing: train-only per-lead normalization.
- A/B activity labels are metadata only. `B` is before activity/rest and `A` is
  after activity/exercise; neither label is passed to the model.

## Architecture

```text
PPG [B, 4, 2000]
  -> 1D residual encoder (Conv1d + GroupNorm + GELU + Dropout1d=0.1)
  -> latent [B, 128, 125] plus three temporal skip features
  -> interpolation upsampling + residual decoder (U-Net style skips)
  -> ECG [B, 4, 2000]
```

The encoder has 405,920 parameters and the decoder has 998,836 parameters
(1.40M total). Linear interpolation is used for temporal upsampling to avoid
transposed-convolution checkerboard artifacts. The baseline objective is
pointwise MSE only.

## Training snapshot

- Seed: 42.
- Epochs: 20.
- Optimizer: AdamW, learning rate `1e-4`, cosine schedule, gradient clipping.
- Best checkpoint: epoch 6, validation loss `1.2730`.
- Test (`best.pth`): RMSE `0.8571`, MAE `0.5515`, PCC `0.2520`, HR error
  `8.96 bpm`, R-peak F1 `0.9038`.
- Train (`best.pth`): RMSE `0.8361`, PCC `0.4674`, HR error `7.75 bpm`,
  R-peak F1 `0.8635`.

The numerical results are a baseline snapshot, not a final clinical claim.
Representative train/test waveforms are in the run's `figures/` directory;
the plotting script selects one window near each A/B group's median MSE.

## Archive contents

The model archive is:

`checkpoints/SensSmartTech_subjectwise-per-lead_baseline_seed42_20ep/`

It contains best/final/epoch-10/epoch-20 checkpoints, the saved config, train
and test evaluation JSON, and the representative-window manifest. Checkpoints
are tracked with Git LFS.
