# v0.53: Wavelet-Supervised QRS Generation

## Motivation

The v0.52 FFT branches separate global frequency energy, but a rectangular
`10-40 Hz` mask cannot tell whether that energy is concentrated at QRS events
or spread across the whole window. v0.53 adds a fixed Symlet-4 stationary
wavelet objective. SWT coefficients retain the original time resolution, so
the loss sees both the scale and the local time of a transient.

This first wavelet experiment intentionally keeps the existing decoder output
in the time domain. It is a controlled loss-side test before introducing a
decoder that predicts wavelet coefficients directly.

## Configuration

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: `42`
- Epochs: `20` (`10` reverse pretraining + `10` frozen cycle)
- Config: `configs/exp_v053_wavelet_frozen_cycle.yaml`
- Run: `runs/senssmarttech_v053_wavelet_frozen_cycle_20ep_seed42/`
- Best checkpoint: `best.pth` (epoch 12, validation `ecg_total=0.8389`)
- Parameters: `1.411M`

The decoder capacity is unchanged from v0.52. The FFT band auxiliary loss is
disabled for this isolation run; the decoder still returns a normal time-domain
ECG tensor. The new loss terms are:

```text
L = 1.00 * L1
  + 0.05 * L_derivative
  + 0.20 * L_wavelet_coeff
  + 0.15 * L_QRS_envelope
```

The wavelet decomposition uses five SWT levels. Detail levels `D2-D4` are
treated as the approximate QRS range at 250 Hz. Coefficients are normalized by
target scale, while the QRS envelope is formed from the squared detail energy
and compared at every time sample. A/B activity labels remain metadata-only.

## Results

| Metric | Train | Test |
|---|---:|---:|
| RMSE | 0.8311 | 0.8295 |
| MAE | 0.4584 | 0.5255 |
| PCC | 0.4705 | 0.3497 |
| HR error (bpm) | 7.5750 | 10.3352 |
| R-peak F1 | 0.8366 | 0.8598 |
| QRS width error (ms) | 9.8292 | 9.6479 |

### Test comparison

| Metric | v0.52 high=2.0 | v0.52 high=4.0 | v0.53 wavelet |
|---|---:|---:|---:|
| RMSE | 0.8552 | 0.8485 | **0.8295** |
| PCC | 0.3144 | 0.3175 | **0.3497** |
| HR error (bpm) | **8.44** | 9.40 | 10.34 |
| R-peak F1 | **0.8920** | 0.8555 | 0.8598 |
| QRS width error (ms) | **8.86** | 14.64 | 9.65 |

The wavelet objective improves global waveform agreement and restores QRS width
accuracy relative to the high=4.0 ablation. It does not yet beat v0.52 on
R-peak F1 or HR error, so it should be interpreted as better local morphology,
not as a complete replacement for the original multi-band configuration.

## Next controlled step

The next experiment should predict grouped wavelet coefficients directly and
reconstruct the signal with inverse SWT/IDWT. The current result justifies that
architecture change, but the peak-alignment metric should remain the primary
selection criterion rather than further increasing coefficient weights.
