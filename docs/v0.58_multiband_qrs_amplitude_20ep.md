# v0.58 Explicit QRS and Amplitude Supervision

## Purpose

v0.58 adds an explicit morphology term to the v0.52 three-band decoder. The
target ECG is used to estimate a detached QRS mask; the mask is a training
signal only and is never passed to the PPG encoder or decoder at inference.
For every ECG lead, the loss compares the detrended local absolute peak and
RMS excursion inside the target QRS region. This prevents a narrow but
under-amplitude spike from satisfying only a high-frequency energy loss.

## Configuration

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: `42`
- Epochs: `20` (`10` reverse pretraining + `10` frozen cycle)
- Config: `configs/exp_v058_multiband_qrs_amplitude_frozen_cycle.yaml`
- Run: `runs/senssmarttech_v058_multiband_qrs_amplitude_frozen_cycle_20ep_seed42/`
- QRS weighted L1: `0.50`
- QRS amplitude peak/RMS: `0.75`
- QRS mask width: `120 ms`

The fused ECG still uses the v0.52 multi-band decoder and frozen reverse
branch. A/B activity labels remain metadata-only.

## Test result (`best.pth`)

| Metric | Test |
|---|---:|
| RMSE | 0.9187 |
| MAE | 0.5710 |
| PCC | 0.2490 |
| HR error (bpm) | 12.28 |
| R-peak F1 | 0.7362 |
| QRS width error (ms) | 20.96 |

The stronger explicit terms over-regularize the fused waveform in this
20-epoch schedule. The global and peak metrics both regress against v0.52, so
v0.58 is retained as a negative control rather than a replacement.

## Reverse/cycle diagnostic (`best.pth`, test)

| Path | L1 |
|---|---:|
| Direct ECG -> PPG | 0.7857 |
| PPG -> ECG_hat -> PPG | 0.6293 |

The cycle improvement is `0.1564` and does not offset the ECG quality
regression.
