# v0.60 High-Band QRS Amplitude Calibration

## Motivation

The v0.58/v0.59 ablation applied amplitude supervision directly to the fused
ECG. That made local spikes more visible, but it also pulled the entire
waveform away from the balanced v0.52 solution. v0.60 tests a narrower
intervention: explicit QRS peak/RMS supervision is applied only to the
projected `10-40 Hz` high-frequency branch. Low-frequency baseline and
mid-frequency P/T morphology remain governed by the v0.52 global objective.

```text
target ECG -> detached QRS mask
high branch, target high band -> QRS peak/RMS amplitude loss
low + mid + high bands -> fixed FFT fusion -> ECG
```

The full target is used only to locate QRS windows. No QRS mask or ECG target
is provided to the deployable PPG->ECG path.

## Configuration

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: `42`
- Epochs: `20` (`10` reverse pretraining + `10` frozen cycle)
- Config: `configs/exp_v060_multiband_high_qrs_amplitude.yaml`
- Run: `runs/senssmarttech_v060_multiband_high_qrs_amplitude_20ep_seed42/`
- Best checkpoint: `best.pth` (epoch 12, selected by validation `ecg_total`)
- High-branch amplitude weight: `0.15`

## Test result (`best.pth`)

| Metric | Train | Test |
|---|---:|---:|
| RMSE | 0.7969 | 0.8856 |
| MAE | 0.4553 | 0.5444 |
| PCC | 0.5344 | 0.2598 |
| HR error (bpm) | 8.16 | 8.11 |
| R-peak F1 | 0.8584 | 0.8926 |
| QRS width error (ms) | 11.04 | 9.27 |

## Comparison with v0.52

| Metric | v0.52 test | v0.60 test |
|---|---:|---:|
| RMSE | 0.8552 | 0.8856 |
| MAE | 0.5345 | 0.5444 |
| PCC | 0.3144 | 0.2598 |
| HR error (bpm) | 8.44 | **8.11** |
| R-peak F1 | 0.8920 | **0.8926** |
| QRS width error (ms) | 8.86 | 9.27 |

The branch-local term avoids the severe degradation of v0.58 and keeps the
peak metrics essentially at v0.52 level. It does not improve global PCC or
QRS width enough to replace v0.52. Therefore v0.52 remains the primary
balanced baseline, while v0.60 is the preferred controlled candidate for
future high-frequency amplitude calibration.
