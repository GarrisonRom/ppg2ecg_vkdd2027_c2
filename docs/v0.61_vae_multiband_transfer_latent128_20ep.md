# v0.61: VAE latent 128 + v0.52 multi-band decoder

## Purpose

This experiment tests the proposed decoder transplant:

```text
PPG -> v0.2 VAE encoder (content/style latent, initialized from v0.2)
    -> exposed temporal skips
    -> v0.52 low/mid/high FFT-projected decoder
    -> ECG
```

The VAE encoder returns a `[B, 128, 125]` temporal latent and three skips
`[B,32,1000]`, `[B,64,500]`, `[B,128,250]`. The first five epochs freeze the
initialized encoder and use posterior means; epochs 6-20 jointly fine-tune
encoder and decoder. GRL and V-REx are active only after the joint stage.
FlowNLL is not included because the deterministic multi-band decoder has no
invertible likelihood path.

## Test result

Checkpoint: `best_reconstruction.pth` (epoch 5, selected by validation
reconstruction loss; `best.pth` is retained as the generic objective
checkpoint).

| Metric | Test mean |
|---|---:|
| RMSE | 0.8696 |
| MAE | 0.5489 |
| PCC | 0.3415 |
| HR error | 9.12 bpm |
| R-peak F1 | 0.9266 |
| R-peak timing error | 25.46 ms |
| QRS width error | 11.85 ms |
| RMSSD error | 52.03 ms |
| QRS amplitude ratio | 0.8568 |
| Peak amplitude ratio | 0.7208 |
| Carotid PTT error | 21.71 ms |
| Brachial PTT error | 21.21 ms |
| Parameters | 1.51M |

Train metrics are RMSE `0.7601`, PCC `0.5884`, HR error `7.03 bpm`, R-peak F1
`0.9008`, and QRS width error `10.94 ms`. The held-out result retains the
strong rhythm transfer of v0.2 while the multi-band decoder improves local
QRS width relative to the original flow path. QRS amplitude remains
conservative, so this is a rhythm/shape candidate rather than a final SCD
monitoring model.

Figures are in `runs/senssmarttech_v061_vae_multiband_transfer_latent128_20ep_seed42/figures/`.
