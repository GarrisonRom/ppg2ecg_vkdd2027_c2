# v0.4: PPGFlowECG-inspired paired latent Flow

## Scope

This is a controlled 20-epoch prototype inspired by the PPGFlowECG design
direction. It is not an exact reproduction of the paper. The experiment keeps
the SensSmartTech subject-wise `22/5/5` split and does not provide A/B activity
labels to the model.

- Dataset: SensSmartTech, `subjectwise_per-lead`
- Input/output: `[B, 4, 2000] -> [B, 4, 2000]`
- Seed: 42
- Epochs: 20
- Config: `configs/exp_v04_ppgflowecg_inspired.yaml`
- Checkpoint: `runs/senssmarttech_v04_ppgflowecg_inspired_20ep_seed42/best.pth`

## Architecture

1. `CardioAlignEncoder` reuses the VAE temporal encoder and exposes posterior
   means and variances for both PPG and paired ECG windows. The same encoder
   weights are used for the two modalities in this first trial.
2. The baseline ECG decoder is trained with three paths: PPG direct
   reconstruction, ECG cross-modal reconstruction, and Flow endpoint
   reconstruction.
3. `LatentRectifiedFlow` learns a conditional vector field from the PPG
   posterior mean to the ECG posterior mean on the downsampled temporal latent
   grid. Inference integrates eight Euler steps and decodes the transported
   latent.
4. CardioAlign objectives include posterior distribution alignment, paired
   InfoNCE, latent Flow matching, and a small VAE KL term.

The first trial deliberately disables GRL/IRM and the v0.3 QRS/STFT additions.
This isolates the PPGFlowECG-inspired aligned-latent hypothesis; those methods
remain available for later factorial ablations.

## Results

| Test metric | v0.1 baseline | v0.2 VAE+Flow+GRL+V-REx | v0.3 QRS objective | v0.4 paired latent Flow |
|---|---:|---:|---:|---:|
| RMSE | 0.8571 | 0.8428 | **0.8254** | 0.8649 |
| MAE | 0.5515 | 0.5332 | **0.5102** | 0.5477 |
| PCC | 0.2520 | **0.3486** | 0.3462 | 0.2729 |
| HR error (bpm) | 8.96 | 10.38 | **8.32** | **8.15** |
| R-peak F1 | 0.9038 | 0.9215 | 0.2449 | **0.9308** |
| QRS width error (ms) | 33.65 | **15.53** | 49.03 | 22.85 |

The v0.4 test result is mixed but informative. It improves R-peak F1 and HR
error over v0.2, while global waveform correlation and QRS width remain behind
the best earlier configuration. The detail panels show that peak timing is
often captured, but generated complexes are still smoother and morphology is
not yet fully aligned. This supports keeping latent alignment and Flow as a
separate research axis rather than claiming it replaces GRL/IRM or QRS-aware
objectives.

### Activity-only analysis

Activity is used only for post-hoc analysis. On the test split, the model has
lower RMSE and higher R-peak F1 in state A than state B, while state B has a
larger HR error. These are diagnostics of motion/rest generalization, not
conditional inputs.

## Next controlled experiments

2. Compare shared versus separate PPG/ECG encoders.
3. Test Flow integration steps and latent Flow weight without changing the
   waveform loss.
4. Only then add a narrowly defined QRS term and report morphology metrics
   together with global error.
