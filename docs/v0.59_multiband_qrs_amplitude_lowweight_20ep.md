# v0.59 Low-Weight QRS and Amplitude Supervision

## Purpose

v0.59 is a conservative follow-up to v0.58. It keeps the v0.52 decoder,
fixed FFT bands, and frozen reverse-cycle schedule, but reduces the explicit
terms to avoid sacrificing broad morphology:

```text
qrs_weighted = 0.10
qrs_amplitude = 0.20
qrs_width_ms = 80
```

The QRS mask is generated from the target ECG and detached. It is not an
input feature and is unavailable during deployment.

## Configuration

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: `42`
- Epochs: `20` (`10` reverse pretraining + `10` frozen cycle)
- Config: `configs/exp_v059_multiband_qrs_amplitude_lowweight.yaml`
- Run: `runs/senssmarttech_v059_multiband_qrs_amplitude_lowweight_20ep_seed42/`
- Checkpoint: `best.pth`

## Test result (`best.pth`)

| Metric | Test |
|---|---:|
| RMSE | 0.9043 |
| MAE | 0.5612 |
| PCC | 0.2850 |
| HR error (bpm) | 9.45 |
| R-peak F1 | 0.8929 |
| QRS width error (ms) | 9.37 |

Relative to v0.52, v0.59 preserves the R-peak F1 and QRS-width improvements,
but global RMSE/MAE/PCC remain worse. Visual inspection shows more visible
local spikes together with occasional overshoot and phase error. It is a
candidate for local-detail studies, not the primary baseline.

## Reverse/cycle diagnostic (`best.pth`, test)

| Path | L1 |
|---|---:|
| Direct ECG -> PPG | 0.7802 |
| PPG -> ECG_hat -> PPG | 0.6055 |

The cycle improvement is `0.1747`; it is treated as a regularization diagnostic,
not evidence that the generated ECG is clinically correct.
