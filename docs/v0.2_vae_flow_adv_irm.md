# v0.2: VAE + Conditional Flow + Adversarial Subject Disentanglement

## Scope

This experiment extends the archived `v0.1` SensSmartTech baseline without
changing the subject-wise split or feeding activity labels to the model.

- Dataset: SensSmartTech, `subjectwise_per-lead`
- Split: 22 train subjects / 5 validation subjects / 5 test subjects
- Input/output: `[B, 4, 2000] -> [B, 4, 2000]`
- Seed: 42
- Epochs: 20
- Checkpoint: `runs/senssmarttech_vae_flow_adv_irm_20ep_seed42/best.pth`
- Best validation objective: epoch 16, `1.2706`

## Architecture

1. `VAEPPGEncoder` uses four residual downsampling blocks and factorizes the
   posterior into `z_content` (64 channels) and `z_style` (64 channels).
2. `ConditionalFlowECGGenerator` first predicts a deterministic ECG context,
   then models residual likelihood with four conditional affine coupling layers.
   Inference uses the zero-noise mode for deterministic waveform metrics;
   `sample()` remains available for stochastic generation.
3. `SubjectDiscriminator` receives only pooled `z_content` through GRL. The
   22-class subject mapping is saved in `subject_mapping.json`.
4. IRM is the stable V-REx auxiliary: the variance of per-subject sample risk,
   where risk is reconstruction MSE plus weighted Flow NLL.

The optimized objective is

```text
MSE + 0.05 * FlowNLL + 0.001 * (KL_content + KL_style)
    + 0.1 * SubjectCE + 0.01 * V-REx
```

GRL lambda warms linearly from 0.1 to 0.3 during the first three epochs.

## Results

| Test metric | v0.1 baseline | v0.2 VAE+Flow+GRL+V-REx |
|---|---:|---:|
| RMSE | 0.8571 | 0.8428 |
| MAE | 0.5515 | 0.5332 |
| PCC | 0.2520 | 0.3486 |
| HR error (bpm) | 8.96 | 10.38 |
| R-peak F1 | 0.9038 | 0.9215 |

Training metrics for v0.2 are RMSE `0.7685`, PCC `0.5668`, HR error
`7.76 bpm`, and R-peak F1 `0.8925`.

## Subject-discriminator diagnostic

For 22 classes, random cross-entropy is `log(22) = 3.091` and random accuracy
is `1/22 = 0.0455`. Across 20 epochs, the recorded training subject loss was
approximately `3.15-3.34` and accuracy `0.02-0.06`; the final values were
`3.218` and `0.021`. This is consistent with a saturated near-random
discriminator under the current GRL setting. The diagnostic is a representation
invariance signal, not proof of causal disentanglement.

The next controlled experiments should vary one factor at a time: GRL weight,
Flow weight, KL weight, and V-REx weight. In particular, HR error increased
slightly despite improved waveform and R-peak metrics, so the current result is
not evidence that every physiological metric improves simultaneously.
