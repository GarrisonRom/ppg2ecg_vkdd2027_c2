# v0.3: QRS-aware reconstruction objective

## Scope

This experiment keeps the v0.2 VAE + conditional Flow + GRL + subject-wise
V-REx architecture and changes the reconstruction objective only. Activity
labels remain metadata-only and are not model inputs.

- Dataset: SensSmartTech, `subjectwise_per-lead`
- Split: 22 train subjects / 5 validation subjects / 5 test subjects
- Input/output: `[B, 4, 2000] -> [B, 4, 2000]`
- Seed: 42
- Epochs: 20
- Checkpoint: `runs/senssmarttech_v03_qrs_vae_flow_adv_irm_20ep_seed42/best.pth`

## Objective

```text
global L1 + 1.0 * target-derived QRS-region L1
         + 0.2 * first-difference L1
         + 0.1 * multi-scale log-STFT L1
         + 0.05 * Flow NLL
         + 0.001 * VAE KL
         + 0.1 * Subject CE
         + 0.01 * V-REx
```

The QRS mask is estimated from target lead II during training and is used only
to weight the loss. It is never provided to the model during inference.

## Test results

| Metric | v0.1 baseline | v0.2 VAE+Flow+GRL+V-REx | v0.3 QRS objective |
|---|---:|---:|---:|
| RMSE | 0.8571 | 0.8428 | **0.8254** |
| MAE | 0.5515 | 0.5332 | **0.5102** |
| PCC | 0.2520 | **0.3486** | 0.3462 |
| HR error (bpm) | 8.96 | 10.38 | **8.32** |
| R-peak F1 | 0.9038 | **0.9215** | 0.2449 |
| QRS width error (ms) | 33.65 | **15.53** | 49.03 |

## Interpretation

v0.3 lowers global waveform error and HR error, but its R-peak F1 and QRS
width error are substantially worse. The detail panels show that generated
waveforms remain smooth while true QRS complexes are sharp. Therefore v0.3 is
an informative negative result, not a replacement for v0.2.

The next revision should keep a global MSE/L1 anchor and reduce or redesign the
QRS term. Before changing the architecture, compare the target-mask coverage,
peak timing, and generated peak count on the same checkpoint. The evaluation
entry point is `scripts/evaluate.py`; it reports waveform, physiology,
activity-stratified, efficiency, and optional distribution metrics.
