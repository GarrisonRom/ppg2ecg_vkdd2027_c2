# v0.55 Wider Encoder with Wavelet-Coefficient Decoder

## Purpose

v0.55 tests whether the high-frequency bottleneck in v0.54 is caused by an
under-capacity PPG Encoder. The main Encoder is widened from `base_channels=32`
to `64` and its temporal latent is expanded from `128` to `256`. The Wavelet
Decoder output width, losses, data split, seed, and frozen reverse-cycle
schedule remain otherwise unchanged. Since wider Encoder skips no longer
match the fixed Decoder width, learned 1x1 projections are used before the
three Decoder skip merges.

## Configuration

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: `42`
- Epochs: `20` (`10` ECG->PPG reverse pretraining + `10` frozen cycle)
- Config: `configs/exp_v055_encoder_wide_wavelet_frozen_cycle.yaml`
- Run: `runs/senssmarttech_v055_encoder_wide_wavelet_frozen_cycle_20ep_seed42/`
- Parameters: `2.85M` (v0.54: `1.45M`)

## Results

| Metric | v0.54 test | v0.55 test | v0.55 train |
|---|---:|---:|---:|
| RMSE | 0.8196 | 0.8302 | 0.8508 |
| MAE | 0.5078 | 0.5169 | 0.4489 |
| PCC | 0.3482 | 0.3361 | 0.4365 |
| HR error (bpm) | 9.27 | 12.64 | 14.35 |
| R-peak F1 | 0.2199 | **0.3471** | 0.3542 |
| R-peak time error (ms) | 89.22 | **71.41** | 72.65 |
| QRS width error (ms) | 54.75 | 55.69 | 53.99 |

The wider Encoder improves peak detection and timing substantially relative to
v0.54, even though RMSE/PCC and HR error do not improve. The remaining QRS
width error and visibly low peak amplitudes show that latent capacity alone is
not sufficient; high-resolution Decoder coefficient heads still need stronger
local reconstruction capacity.

For the cross-version matrix, the saved `best.pth` was also re-evaluated and
gives RMSE `0.8302`, PCC `0.3361`, HR error `12.64 bpm`, R-peak F1 `0.3471`, and
QRS width error `55.69 ms`. These values match the `best.pth` row in the
cross-version matrix; an older final-checkpoint snapshot is retained separately
in the run directory.

## Interpretation

This is evidence for an Encoder-side bottleneck, not proof that the Decoder is
already adequate. The earlier component diagnostic showed that the same
Wavelet Decoder can fit high-frequency coefficients from real ECG input, while
PPG input remains amplitude-limited. v0.55 reduces that gap but does not close
it.

post-hoc evaluation and are never passed to the model.

## Next controlled experiment

Keep the v0.55 Encoder, but widen only the D1/D2 coefficient branches and add
local high-resolution residual blocks. Compare that against v0.55 with the
Decoder unchanged; this will separate residual Decoder capacity from the
already measured Encoder benefit.
