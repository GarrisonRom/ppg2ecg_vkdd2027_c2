# v0.52: Multi-Band ECG Generation with Frozen Reverse Cycle

## Motivation

ECG morphology is multi-scale: baseline drift is mostly below `0.5 Hz`, P/T
wave morphology and rhythm occupy roughly `0.5-10 Hz`, and QRS energy is
concentrated around `10-40 Hz`. A pointwise loss sees all samples uniformly and
can therefore spend most of its capacity on the lower-frequency waveform while
under-training sharp QRS transitions. v0.52 makes the three scales explicit.

## Architecture

The main decoder remains a time-domain residual decoder, but it has three
parallel output heads. Each head is projected with a fixed FFT mask and the
projected signals are fused in the time domain:

```text
PPG -> shared temporal encoder -> shared decoder features
                                      |-> low head  -> FFT 0-0.5 Hz  --+
                                      |-> mid head  -> FFT 0.5-10 Hz  -+-> 1x1 fusion -> ECG
                                      |-> high head -> FFT 10-40 Hz  --+

ECG -> separately supervised reverse ECG->PPG branch
PPG -> ECG_hat -> frozen reverse branch -> PPG_cycle
```

This is a deliberate first frequency experiment, not a wavelet model. The
decoder still returns a normal `[B, 4, 2000]` ECG tensor, so existing metrics and
visualization scripts remain unchanged. The fixed FFT projection avoids adding
wavelet boundary conventions and lets the experiment isolate the effect of
frequency separation. Frequencies above `40 Hz` are not represented by the
three-band output and are a known limitation of this version.

- Dataset: SensSmartTech, subject-wise `22/5/5`
- Sampling: `250 Hz`, window length `2000`
- Seed: 42
- Epochs: 20 (10 reverse pretraining + 10 frozen-cycle)
- Config: `configs/exp_v052_multiband_frozen_cycle.yaml`
- Run: `runs/senssmarttech_v052_multiband_frozen_cycle_20ep_seed42/`
- Best checkpoint: `best.pth` (epoch 12, selected by validation `ecg_total`)

## Loss design

The ordinary reconstruction objective uses L1, a small derivative term, and a
small multi-scale STFT term:

```text
L_signal = 1.0 * L1 + 0.05 * L_derivative + 0.05 * L_STFT
```

For each band, the target and prediction are projected with the same FFT mask.
The L1 error is divided by the target band energy (with a floor of `0.05`) so
that the numerically smaller low/high components do not disappear under the
global loss. The weighted auxiliary term is:

```text
L_band = 0.25 * (0.5 * L_low_norm
               + 1.0 * L_mid_norm
               + 2.0 * L_high_norm)
```

The frozen-cycle schedule is inherited from v0.51:

```text
L_stage1 = L_signal + L_band + 1.0 * L1(PPG_direct, PPG)
L_stage2 = L_signal + L_band
         + 1.0 * L1(PPG_direct, PPG)
         + 0.5 * L1(PPG_cycle, PPG)
```

A/B activity labels are metadata-only and are used only for stratified
evaluation.

## Results

The deployable path is PPG->ECG; the reverse branch is not an inference input.

| Metric | Train | Test |
|---|---:|---:|
| RMSE | 0.7718 | 0.8552 |
| MAE | 0.4394 | 0.5345 |
| PCC | 0.5727 | 0.3144 |
| HR error (bpm) | 9.69 | 8.44 |
| R-peak F1 | 0.8547 | 0.8920 |
| QRS width error (ms) | 10.62 | 8.86 |

Compared with v0.51 on the test split:

| Metric | v0.51 | v0.52 | Change |
|---|---:|---:|---:|
| RMSE | 0.8454 | 0.8552 | slightly worse |
| PCC | 0.3060 | 0.3144 | better |
| HR error (bpm) | 14.73 | 8.44 | better |
| R-peak F1 | 0.6018 | 0.8920 | better |
| QRS width error (ms) | 34.03 | 8.86 | better |

The result supports the frequency-separation hypothesis: morphology and rhythm
metrics improve sharply even though the global pointwise RMSE does not. The
model should therefore be judged with both waveform and physiology metrics, not
RMSE alone.

## Reverse/cycle diagnostics

| Split | Direct ECG->PPG L1 | Cycle PPG->ECG_hat->PPG L1 |
|---|---:|---:|
| Train | 0.4800 | 0.5731 |
| Test | 0.7742 | 0.5954 |

The test cycle error is lower than the direct reverse error, while the train
cycle error is higher. As in v0.51, cycle loss is treated as a constraint and
not as evidence that the ECG waveform is correct by itself.
