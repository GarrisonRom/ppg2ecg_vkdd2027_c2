# v0.63: VAE multi-band decoder with light QRS/peak supervision

## Purpose

This experiment keeps the v0.61 VAE encoder, temporal skips, multi-band
decoder, GRL, V-REx, five-epoch decoder warm-up, split, seed, and 20-epoch
budget. It adds two low-weight target-only training terms:

- QRS amplitude/energy supervision with weight `0.05`;
- differentiable Haar QRS peak-interval supervision with weight `0.05`.

The ECG target is used only to construct auxiliary training masks/anchors. No
activity label or target ECG feature is supplied to the inference model.

## Test result

Checkpoint: `best.pth`, selected by validation `total` (`1.2726`).

| Metric | Test mean |
|---|---:|
| RMSE | 0.8569 |
| MAE | 0.5403 |
| PCC | 0.3291 |
| HR error | 9.77 bpm |
| R-peak F1 | 0.9188 |
| R-peak timing error | 26.07 ms |
| QRS width error | 13.76 ms |
| RMSSD error | 53.80 ms |
| QRS amplitude ratio | 0.7777 |
| Carotid PTT error | 22.61 ms |
| Brachial PTT error | 21.63 ms |
| Parameters | 1.51M |

Compared with v0.61, the added terms do not improve the held-out R-peak F1,
peak timing, QRS width, or global PCC. This is retained as a controlled
negative result: the current target-derived peak objective is not enough to
overcome the VAE/GRL joint-training trade-off at this weight and schedule.

Figures are in
`runs/senssmarttech_v063_vae_multiband_qrs_peak_20ep_seed42/figures/`.
