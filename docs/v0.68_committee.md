# v0.68 Committee Archive

## Version

- Version: `v0.68`
- Dataset: SensSmartTech
- Task: four-channel PPG -> four-lead ECG (`I/II/V3/V4`)
- Sampling: `250 Hz`, `2000` samples (`8 s`)
- Subject split: `22 / 5 / 5` train/validation/test subjects
- Seed: `42`
- Activity labels A/B: metadata-only evaluation groups; never model inputs
- Model parameters: intentionally excluded from this Git commit

## Architecture

The v0.68 experiment is built on the v0.67 residual high-skip backbone:

```text
PPG [B, 4, 2000]
  -> VAEPPGEncoder
       - residual 1-D convolutional downsampling
       - content latent: 64 channels
       - style latent: 64 channels
       - concatenated temporal latent: [B, 128, 125]
       - optional full-resolution feature: [B, 16, 2000]
  -> MultiBandECGDecoder
       - low band: 0-0.5 Hz
       - mid band: 0.5-10 Hz
       - high band: 10-40 Hz
       - fixed FFT projection and time-domain fusion
       - high-frequency residual skip with zero-started gain
  -> ECG [B, 4, 2000]
```

The encoder also feeds a subject discriminator through a gradient reversal
layer. Subject-wise V-REx is used as an auxiliary invariance constraint. The
main supervised objective remains reconstruction plus a small derivative term
and normalized low/mid/high band losses. The high-skip residual is

```text
high_features = features + tanh(alpha) * skip_residual
```

with `alpha=0` at initialization, so the new local path starts as an exact
control path and only contributes after learning a non-zero gain.

## PatchGAN addition

v0.68 adds an optional lightweight conditional 1-D PatchGAN. It receives the
paired input `[PPG, ECG]` and outputs a length-125 patch-logit map. It uses
hinge loss, a separate AdamW discriminator optimizer, and a low generator
weight (`0.02`). The discriminator and optimizer states are saved in the local
run checkpoints for auditability, but those checkpoints are not versioned.

The PatchGAN is an experimental ablation, not the default production model.
It is intentionally configurable and can be disabled without changing the
v0.67/v0.61 supervised path.

## Results

The residual high-skip control reached the following held-out test values:

| Run | RMSE | PCC | HR error (bpm) | R-peak F1 | QRS width error (ms) |
|---|---:|---:|---:|---:|---:|
| v0.67-control | 0.8549 | 0.3311 | 8.5843 | 0.9257 | 13.5142 |
| v0.67-gated | 0.8417 | 0.3400 | 9.8992 | 0.9245 | 11.3606 |
| v0.67-residual | 0.8435 | 0.3322 | 10.0415 | 0.9179 | 13.7256 |
| v0.68-PatchGAN | 0.8340 | 0.3331 | 11.5771 | 0.3234 | 78.3057 |

The residual gate learned `alpha=0.0245`, confirming that it remained a small
correction. It did not reproduce the full gated-run gain, so it is retained as
a stability control.

The PatchGAN run was stopped by early stopping at epoch 6. Its discriminator
loss fell from `0.1431` to `0.0144`, while the generator adversarial loss rose
from `2.11` to `3.27`. R-peak F1 and QRS width degraded on the training split as
well as the test split. This indicates discriminator saturation and objective
mismatch, not merely cross-subject overfitting. PatchGAN is therefore archived
as a negative adversarial control and is not enabled in the recommended main
line.

## Git scope

This commit contains source code, experiment configurations, evaluation tools,
figures, and documentation. It deliberately excludes newly trained model
weights, run directories, prediction arrays, and raw/processed data. The local
run directories remain available for analysis on the workstation and can be
recreated from the committed configurations.
