# v0.2 与 v0.52 模型与架构对比

> 主比较对象是仓库中的 `v0.52_multiband_frozen_cycle`，也就是实验矩阵标注的 primary balanced baseline。仓库另有 `v0.52_highfreq4`，它只把高频权重从 `2.0` 改为 `4.0`，文末单独说明。

## 1. 一句话结论

- **v0.2** 解决的是“潜变量如何组织、如何建模输出不确定性、如何削弱 subject-specific 信息”：VAE content/style factorization + conditional Flow + GRL subject discriminator + V-REx。
- **v0.52** 解决的是“ECG 的不同时间尺度如何分别学习”：确定性 skip-connected encoder/decoder + 固定 FFT 三频带输出头 + 冻结的 ECG→PPG reverse cycle。
- 两版的 latent 通道数都为 `128`，但语义完全不同：v0.2 是采样的 `z_content + z_style`，v0.52 是确定性的时序 feature。不能因为 latent shape 一样就认为模型容量或归纳偏置一样。

架构总图： [PNG 预览图](v0.2_vs_v0.52_architecture.png) / [SVG 矢量图](v0.2_vs_v0.52_architecture.svg)；可编辑源：[Mermaid 源文件](v0.2_vs_v0.52_architecture.mmd)。

## 3. v0.2 的真实架构

### 3.1 PPG 编码器

实现：[`src/models/vae_flow.py`](../src/models/vae_flow.py) 中的 `VAEPPGEncoder`，基础残差块来自 [`src/models/baseline.py`](../src/models/baseline.py)。配置为 `base_channels=32`、`latent_dim=128`、`content_dim=64`、`style_dim=64`。

| stage | 操作 | 输出尺寸 |
|---|---|---|
| input | 4 路 PPG | `[B,4,2000]` |
| stem | residual block，stride=2 | `[B,32,1000]` |
| enc1 | residual block，stride=2 | `[B,64,500]` |
| enc2 | residual block，stride=2 | `[B,128,250]` |
| shared | residual block，stride=2 | `[B,128,125]` |
| posterior heads | `mu/logvar` 各自拆成 content/style | `zc, zs: [B,64,125]` |
| sampled latent | `cat(zc, zs)` | `latent: [B,128,125]` |

训练时使用 reparameterization sampling；eval 模式使用 `mu`。注意，`VAEPPGEncoder` 没有返回 baseline decoder 所需的 `skips`，所以 v0.2 主 decoder 实际上是 **latent-only 解码**，不是 skip-connected U-Net。

### 3.2 Conditional Flow ECG generator

实现：`ConditionalFlowECGGenerator`。它由两层逻辑组成：

1. `context_decoder` 是一个 `BaselineECGDecoder(base_channels=24)`，把 `[B,128,125]` 解码成确定性 ECG context `[B,4,2000]`。由于没有 encoder skips，decoder 中对应的 skip 输入使用零张量。
2. context 先经过 `1x1 log_scale_head`，再经过 4 个交替 mask 的 `ConditionalAffineCoupling1D`。每个 coupling 的条件都是 context ECG，hidden channels 为 `32`。

训练时对真实 ECG 计算归一化 Flow NLL：

```text
z = (ECG - context) * exp(-log_scale)
z -> 4 x conditional affine coupling
NLL = normalized Gaussian log likelihood - log determinant
```

推理时 `forward()` 使用 zero-noise mode，因此已有评估指标对应的是确定性输出；`sample()` 仍保留随机 ECG 生成能力。

### 3.3 Subject disentanglement 与 IRM

`z_content` 沿时间维平均为 `[B,64]`，只经过 GRL 送入 `64 -> 128 -> 22` 的 subject classifier。GRL 系数在前 3 个 epoch 从 `0.1` warm up 到 `0.3`。subject head 试图识别 subject，而 GRL 让编码器反向地减少 subject 信息。

V-REx 按 subject 构造 environment，先得到每个样本的：

```text
risk_i = reconstruction_MSE_i + 0.05 * FlowNLL_i
```

然后计算各 subject risk 均值的方差。完整目标是：

```text
L_v02 = MSE
      + 0.05 * FlowNLL
      + 0.001 * (KL_content + KL_style)
      + 0.1 * SubjectCE
      + 0.01 * V-REx
```

其中 subject CE 由 classifier 正常最小化，但通过 GRL 对 encoder 的梯度取反；A/B 活动标签没有进入模型。

## 4. v0.52 的真实架构

### 4.1 PPG encoder 与 skip decoder

实现：[`src/models/baseline.py`](../src/models/baseline.py) 的 `BaselinePPGEncoder`，以及 [`src/models/band_decoder.py`](../src/models/band_decoder.py) 的 `MultiBandECGDecoder`。v0.52 的 encoder 不产生 posterior、不采样，也没有 content/style 拆分。

| stage | encoder 输出 | decoder 对应操作 |
|---|---|---|
| stem | `[B,32,1000]` | 保存 `skip0` |
| enc1 | `[B,64,500]` | 保存 `skip1` |
| enc2 | `[B,128,250]` | 保存 `skip2` |
| bottleneck | `[B,128,125]` | latent feature |
| up1 | `[B,128,250]` | 与 `skip2` 拼接，`256 -> 128` |
| up2 | `[B,64,500]` | 与 `skip1` 拼接，`128 -> 64` |
| up3 | `[B,32,1000]` | 与 `skip0` 拼接，`64 -> 32` |
| up4 | `[B,16,2000]` | 进入三个频带 head |

每个频带 head 都是 `Conv1d(16,16,7) -> GELU -> Conv1d(16,4,7)`，先在时域产生一个 4 导联候选分量，再进行固定 FFT 投影：

```text
low  = FFT^-1(FFT(raw_low)  * mask[0, 0.0-0.5 Hz])
mid  = FFT^-1(FFT(raw_mid)  * mask[1, 0.5-10 Hz])
high = FFT^-1(FFT(raw_high) * mask[2, 10-40 Hz])
ECG_hat = 1x1_fusion([low, mid, high])
```

`1x1_fusion` 的输入是 12 个通道，输出 4 个通道，并初始化为每个 lead 的三频带相加。`T=2000、Fs=250` 时 FFT 频率分辨率为 `0.125 Hz`。`40 Hz` 以上的频率没有显式输出分支，这是该版本的已知边界。

### 4.2 v0.52 的频带监督

普通 ECG 重构使用：

```text
L_signal = 1.0 * L1
          + 0.05 * L_derivative
          + 0.05 * L_multi_scale_STFT
```

频带目标与预测使用同一组固定 FFT mask，并按每个 sample/lead 的目标频带平均绝对能量归一化，能量下限为 `0.05`：

```text
L_band = 0.25 * (0.5 * L_low_norm
               + 1.0 * L_mid_norm
               + 2.0 * L_high_norm)
```

所以 v0.52 的“高频更重要”不是把所有 loss 乘 2，而是在总权重 `0.25` 内对归一化后的 `10-40 Hz` 分支使用相对权重 2。频带 mask 是固定的，没有额外可学习频率参数。

### 4.3 冻结 reverse cycle

reverse branch 由一套独立的 baseline encoder/decoder 组成：

```text
ECG [B,4,2000]
  -> reverse BaselinePPGEncoder
  -> latent [B,128,125]
  -> reverse BaselineECGDecoder
  -> PPG_direct [B,4,2000]
```

每个 batch 还把生成 ECG 送入同一个 reverse branch：

```text
PPG -> ECG_hat -> frozen reverse branch -> PPG_cycle
```

训练分两阶段：

| 阶段 | epoch | 训练逻辑 |
|---|---:|---|
| reverse pretrain | 1-10 | `L_signal + L_band + 1.0*L1(PPG_direct, PPG)`；同时保存 reverse_pretrained checkpoint |
| frozen cycle | 11-20 | 冻结 reverse encoder/decoder；优化 `L_signal + L_band + 1.0*direct L1 + 0.5*cycle L1` |

需要特别注意：第二阶段 reverse branch 参数被冻结后，`L1(PPG_direct, PPG)` 对主 PPG→ECG 路径不提供梯度；真正约束生成 ECG 的是 `PPG_cycle` 这条路径。推理时 reverse branch 不参与输入和输出。

## 5. 结构差异总表

| 维度 | v0.2 | v0.52 | 直接影响 |
|---|---|---|---|
| encoder 类型 | VAE residual encoder | deterministic residual encoder | v0.2 有 posterior uncertainty，v0.52 输出更直接 |
| latent 语义 | content 64 + style 64 | 单一 128-channel temporal feature | v0.2 可施加 disentanglement，v0.52 不显式拆分语义 |
| temporal skips | 主路径没有 skips | 3 组 skip connections | v0.52 更利于把高分辨率时序细节送到 decoder |
| ECG generator | context CNN + 4 coupling Flow | 3 heads + fixed FFT projection + fusion | v0.2 建模 residual likelihood，v0.52 建模频带分工 |
| 输出随机性 | 训练随机；推理 zero-noise | 确定性 | v0.2 可扩展采样，v0.52 更容易复现单次输出 |
| 频率先验 | 无显式频带 head | 0-0.5 / 0.5-10 / 10-40 Hz | v0.52 直接保护 QRS 频带的监督信号 |
| reverse branch | 无 | 独立 ECG→PPG branch | v0.52 用 cycle compatibility 约束 PPG→ECG |
| reverse 训练 | 不适用 | 10 epoch pretrain + 10 epoch freeze | v0.52 训练图更大，但部署图不变 |
| subject invariance | GRL + subject CE + V-REx | 无 GRL / IRM | v0.2 针对跨 subject 表征，v0.52 针对波形多尺度 |
| 主 loss | MSE + Flow/KL/subject/IRM | L1 + derivative + STFT + band + cycle | 两版优化的“好波形”定义不同 |

## 6. 参数量与计算图

参数量由当前源码按配置实例化统计，单位为 million parameters：

| 模块 | v0.2 | v0.52 |
|---|---:|---:|
| PPG encoder | 0.504M | 0.406M |
| 主 ECG decoder / generator | 0.618M | 1.005M |
| subject head | 0.011M | 0 |
| reverse encoder | 0 | 0.406M |
| reverse decoder | 0 | 0.999M |
| 部署主路径 | 1.122M | 1.411M |
| 训练图总参数 | 1.134M | 2.816M |

v0.52 的 `2.816M` 不能直接理解为部署时的模型大小：reverse branch 训练第 10 个 epoch 后冻结，部署只保存和调用 PPG→ECG 主路径即可。相反，v0.2 的 subject head虽然参与训练，但推理 ECG 不需要调用它。

## 7. 已有 test 结果如何解读

| 指标 | v0.2 | v0.52 | 差异（v0.52 - v0.2） |
|---|---:|---:|---:|
| RMSE | 0.8428 | 0.8552 | +0.0124 |
| MAE | 0.5332 | 0.5345 | +0.0013 |
| PCC | 0.3486 | 0.3144 | -0.0342 |
| HR error | 10.38 bpm | 8.44 bpm | -1.94 bpm |
| R-peak F1 | 0.9215 | 0.8920 | -0.0295 |
| QRS width error | 15.53 ms | 8.85 ms* | -6.68 ms |

`*` 版本文档的四舍五入记录为 `8.86 ms`，实验矩阵记录为 `8.85 ms`，不影响结论。

因此不能说 v0.52 在所有指标上都超过 v0.2：

- v0.2 的全局误差、PCC 和 R-peak F1 更好，说明 VAE/Flow 表征在当前实验中仍然保留了较强的整体形状和峰检测能力。
- v0.52 的 HR error 和 QRS width error 更好，说明固定频带监督和冻结 reverse cycle 更直接改善了节律/QRS 宽度这一类生理指标。
- 这两个版本代表两条不同研究轴：**v0.2 是 representation/distribution axis，v0.52 是 multi-scale waveform axis**。后续若要融合，建议把 v0.52 的 multi-band decoder 加到确定性或 VAE encoder 上，按单因素实验分别打开 Flow、GRL、IRM，而不是一次性全部叠加。

## 8. v0.52-highfreq4 的位置

`configs/exp_v052_highfreq4_frozen_cycle.yaml` 与基础 v0.52 架构完全相同，只改：

```text
low=0.5, mid=1.0, high=2.0  ->  low=0.5, mid=1.0, high=4.0
```

测试结果从 v0.52 的 `RMSE 0.8552 / F1 0.8920 / QRS width 8.86 ms` 变为 `0.8485 / 0.8555 / 14.64 ms`。它说明单纯继续提高高频能量权重会牺牲峰定位和 QRS 宽度，不能作为 v0.52 的默认替代。
